# PNP-008 conformance audit

Relay Federation & Network Resilience.

Read-only audit by a delegated reviewer (Opus), made by reading the spec, the tests and the code; nothing was run. The tree read was the worktree of branch `test/conformance-100` while it stood three commits after d8ceedb; those commits changed nothing in the code audited here except nine lines of `parolnet-relay-server/src/main.rs` (the idle-close fix). The implementing agent wrote this file from the reviewer's report and did not re-check the verdicts.

## Spec/code mismatches

As reported by the reviewer; not re-checked.

- MUST-001 / MUST-007: signatures cover hand-rolled concatenations, not deterministic CBOR (parolnet-relay/src/directory.rs:79-103; parolnet-protocol/src/federation.rs:215-245, 282-291).
- MUST-002: the endorsement signs `SHA-256(peer_id || endorsed_at || expires_at)`, not the descriptor with its signature (parolnet-relay/src/authority.rs:72-78), so it is not bound to the descriptor's keys or address.
- MUST-026: IBLT cell indices are unseeded `SHA-256(i || key)`, with no HKDF and no `sync_id` (parolnet-mesh/src/sync.rs:135-146).
- MUST-027 / MUST-031: descriptors expire at 24 h (`MAX_DESCRIPTOR_AGE_SECS = 86400`, directory.rs:31, 327-329, 506), the spec says 7 days; `verify_threshold` skips the self-signature and age checks (authority.rs:98-134).
- MUST-030: on equal timestamps the first arrival is kept (directory.rs:524-528); the spec requires the lexicographically smaller CBOR encoding.
- MUST-016: for IPv6, `subnet_prefix` uses /16, not /32 (directory.rs:58-75).
- MUST-038 / MUST-042: bundle descriptors carry no endorsements; only the bundle signature is checked (bootstrap/bundle.rs:48-58, 126-165).
- MUST-043 / MUST-072: descriptors are deserialized before the signature is verified (bundle.rs:176, dns.rs:39-43, https.rs:73).
- MUST-076: `content_type_accepted` accepts any `application/cbor;...` parameter (https.rs:17-21).
- MUST-080 / MUST-084: `FederationFrame` has only Sync and Heartbeat; an unknown variant is a CBOR error and closes with 1000, not 4002 (federation_codec.rs:76-83, 126-140).
- MUST-078: frames are an externally tagged ciborium enum, so the first byte is a map header, not a 0x06 / 0x07 discriminator (federation_codec.rs:41-45, 89-91).
- MUST-077: `FEDERATION_SUBPROTOCOL` is exported (federation_codec.rs:24) although the spec says the sub-protocol header is absent; it is unused.
- The relay server's `/federation/v1` handler decodes frames and discards them: no handshake, no call into `FederationManager` (parolnet-relay-server/src/main.rs:1036-1076). The federation state machine exists only in the library.
- `EMBEDDED_SEED_CBOR = &[]` (bootstrap/seed.rs:20) and there is no bootstrap orchestrator, which leaves MUST-040, -050, -075, the cooldown of MUST-074 and SHOULD-006 / -008 unimplemented.
- MUST-066: the server rate-limits with `rate_limit.rs` `LOOKUP_RATE_LIMIT`; the `PresenceConfig.lookup_rate_limit_per_sec` field the test checks is never read.
- MUST-004 / -005 / -012: the mesh accepts and forwards any gossip `payload_type`, 0x06 to 0x08 included (parolnet-mesh/src/gossip.rs:418-420).
